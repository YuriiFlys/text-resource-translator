# Глосарій продукту Acme Files (en → uk)

## Терміни інтерфейсу

- **project** — проєкт (не «проект»)
- **dashboard** — панель керування
- **sync / synchronize** — синхронізувати, синхронізація
- **sign in / sign out** — увійти / вийти
- **settings** — налаштування
- **profile** — профіль
- **upload** — завантажити (на сервер); **download** — скачати
- **member** — учасник
- **storage** — сховище
- **notifications** — сповіщення
- **dark mode** — темна тема

## Не перекладати

- Acme, Acme Files — назва продукту
- API, URL, ID
